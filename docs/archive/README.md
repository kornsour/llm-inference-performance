# Archive

This folder holds historical and superseded documentation — old plans, notes,
and records that were relevant at some point in the project's history but have
since been replaced or completed.

**Do not use anything in this folder to understand the current state of the
project, and do not use it to guide new work.** Content here reflects past
decisions, plans, or state that may no longer be accurate or applicable.
Current documentation lives at the repository root and under `docs/` (outside
this folder).

Contributors and coding agents (Claude, Codex, Copilot, Gemini, etc.) should
treat everything under `docs/archive/` as historical context only, never as a
source of truth for how the project works today or what to build next.
